2

5Reproducir desde la raíz del repositorio, también en Windows PowerShell:
6
7```powershell
8uv run python scripts/rank_companies.py --all-cuts --format markdown
9```
10
11La salida del comando reproduce las tres secciones siguientes. El formato JSON de la misma CLI permite inspeccionar IDs, contribuciones, fuentes, estados, fechas y notas. Los empates se resuelven por ID público: varias cuentas seleccionadas no tienen una ventaja comercial acreditada sobre otras empatadas. No se modificaron pesos para obtener estas selecciones.
